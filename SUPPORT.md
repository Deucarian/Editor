# Support for Deucarian Editor

Use [GitHub Issues](https://github.com/Deucarian/Editor/issues) for reproducible shared editor-shell, icon/resource, style-token, or UI Toolkit helper defects; documentation gaps; and narrowly scoped feature requests. Search existing issues before opening a new one.

Include the package version, Unity editor version and operating system, active editor theme, the smallest reproduction, screenshots when useful, expected and actual behavior, and the full editor exception or stack trace.

`main` is the stable package channel. `develop` is a preview channel and may change before promotion. Please reproduce against the applicable current channel before reporting an older snapshot.

Do not disclose vulnerabilities, private project data, or licensed assets in an issue. Follow [SECURITY.md](SECURITY.md) for private security reports.

Support is provided on a best-effort basis. Domain-package behavior and Unity editor defects outside this package's shared editor-shell boundary are out of scope.
